The generated wordmark is an output of the font, not a renamed or modified font. GenerateIcon.swift registers it only for that process and does not install any system font.

The generated glyph output uses a narrow vector contour compensation to match the existing Gao series ink weight, followed by measured outline placement. This alters only the output vector drawing, not the bundled font. No raster editing, texture, gradient or competitor asset is involved.

Regenerate from the project directory:

```sh
xcrun swift -module-cache-path /private/tmp/GaoJieTuModuleCache Scripts/GenerateIcon.swift
xcrun swift -module-cache-path /private/tmp/GaoJieTuModuleCache Scripts/MakeIcon.swift Assets/AppIcon.png Assets/AppIcon.icns
```
