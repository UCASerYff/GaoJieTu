# 搞截图

原生 macOS 截图、标注、贴图、录屏/独立录音、GIF、本机 OCR 与翻译工作台。Bundle ID `com.gaoseries.GaoJieTu`，V1.03 / build 4，Apple Silicon，macOS 14+。不采集遥测，不默认保存截图历史，不监听剪贴板或全局划词。

当前为 V1.03 验收候选。针对性回归、文件级安装核验与实际操作验收分别记录；编译或生成媒体通过不能替代真实屏幕、声音和系统权限结果。系统授权、采集与语言包下载按用户明确授权操作；实际验收前保留旧程序与回滚材料，正式稳定 Release 在验收通过后发布。

## V1.03 修正

- 修复自动原文语言模式的准备顺序：自动会话直接接收待译文字，由 Apple Translation 识别原文；不在尚无文字时调用 `prepareTranslation()`。明确语言模式保留准备步骤，系统无法识别时仍需人工选择，不固定为英语、不默认转云翻译。
- 显示系统实际识别的原文语言；外部结果记录请求的 `auto` 模式与实际响应语言。取消、输入快照、operationID / requestID 隔离保留，迟到结果不可完成新请求；错误区分准备和翻译阶段。
- 构建目录、安装暂存和新备份使用 `.noindex` 容器；发行核验拒绝源码包中的构建产物。收尾仍须清除展开的构建 App、按精确路径检查本 Bundle ID 的登记和搜索入口。
- 本轮仅修复并专项验收公开合成文字的本机自动翻译；对应实机结果见 Release 说明。本应用其他待验收项目不因此视为通过。

## V1.02 修正

V1.01 已安装并预发布后，在实际窗口验收中发现 Dock 的透明全屏浮层可能截走窗口命中。V1.02 排除系统浮层，并按事件自身坐标定位点击与拖选；普通截图验收继续进行。

## V1.01 改动

- 窗口选择按实际前后顺序定位；长截图向选定内容区滚动，接缝预览随重叠滑块更新；修正小数坐标的像素裁切和 Retina 贴图原始像素比例。
- 录制暂停时间线与无效 GIF 参数增加边界保护；系统音频设备不可确定时停止采集；结束补帧失败时保留可恢复的已有媒体并报告实际时长。
- 翻译与外部任务使用独立身份，取消后拒收迟到结果；混合原生文字和扫描图像的 PDF 补充识别层。仅请求 PDF 时，未完成的 OCR 文字也有私有恢复记录，不额外发送未请求附件。
- 备份兼容实际交接 payload 路径，拒绝歧义和摘要冲突。设置页可主动复制当前运行程序的签名与权限状态，过程不采集屏幕或声音。
- 程序内记录干净源码提交；打包核对完整源码、版本、能力声明和 SHA256，可进一步逐文件核对安装程序。源码包与发行资产排除测试实录、个人资料和备份。

## 使用

- ⌃⌥⌘2 区域截图，⌃⌥⌘3 用户明确触发静默截图 OCR。拖选后 Return 确认，Esc 取消；方向键移动，Option 调尺寸，Shift 以10点移动。快捷键冲突会报告，可用菜单动作。
- 截图支持区域、窗口、屏幕、延时、多窗口；鼠标/阴影可选。设置中选截图后的标注、复制或保存策略。标注可输出 PNG/JPEG/TIFF/HEIC、最长边与压缩参数，另存原图+图层编辑包；实心遮盖并栅格化用于敏感内容，模糊不保证保密。
- 贴图右键可调缩放、透明、置顶、鼠标穿透、复制与编辑。主界面可恢复全部贴图交互。只有主动“持久保存”才写入资料目录。
- 长截图先选择窗口与内容区域，再通过不激活控制条逐帧捕获或单次滚动。目标焦点、窗口身份/位置/尺寸改变会暂停；低置信度接缝必须预览并确认。当前为同一显示器、垂直向下、有界内存实现，固定侧栏、动画、无限滚动与重复内容须人工核对。
- OCR 支持用户选择图片/PDF 批次、Finder 打开、主动剪贴板与截图入口。查询 Vision 实际语言；准确与快速模式支持语种不同。逐页进度、取消、失败页重试、对比度与去倾斜；输出 TXT、Markdown、JSON、定位文本层可搜索 PDF。原 PDF 不覆盖。
- 录屏与仅录音独立入口，系统内部声音与麦克风分别选。MOV 双音源分轨，M4A 混音导出。独立麦克风录音 macOS14 可用；SCK 麦克风伴录与点击高亮需要15+。暂停修正时间线，掉帧/音频缓冲可见；异常中间文件与恢复说明保留，不能保证崩溃 MOV 可修复。
- GIF 使用系统 ImageIO，支持时段、尺寸、裁剪、帧率、调色、容量估计和取消，不含音频，最多256色。
- 翻译使用 Apple Translation，macOS15+，受语言组合及已安装语言包限制。输入、主动剪贴板、OCR结果和系统服务可进入；划词监听由搞操作承担。没有默认云 OCR/翻译提供方或 API 密钥。

## 数据与安装

资料：`~/Library/Application Support/GaoSeries/GaoJieTu`。备份：同级 `GaoJieTu-Backups`。设置、历史附件、持久贴图、交接副本均在本应用范围；用户导出的文件保持在所选位置，钥匙串不迁移或重置。

损坏、过新 schema、主记录缺失或附件摘要冲突会停止写入。历史可关闭、设置期限与容量；过期或用户删除的历史有私有恢复副本，完整备份也可能保留旧内容。请按自己的隐私需求管理这些恢复资料。会话 OCR 图像放私有临时目录，正常退出清理。

```sh
Scripts/test-actions.sh         # 翻译取消身份、混合PDF与OCR恢复的针对性回归，无GUI
Scripts/test-translation.sh     # 自动翻译调用顺序、取消与请求隔离，无GUI/下载
python3 Scripts/test_release.py # 发行来源、版本、摘要与安装字节核验的合成测试
python3 Scripts/test_backup.py  # 备份/回滚边界测试，不操作真实安装
# Scripts/test.sh 为完整旧回归，含窗口测试；按需明确选择，不默认执行
Scripts/build.sh                # arm64 原生程序，本地签名
Scripts/package.sh              # 先提交经审核源码，再归档 HEAD
Scripts/install.sh              # 完整备份+恢复演练，安全替换，不启动程序
Scripts/rollback.sh --verify-only
Scripts/rollback.sh             # 恢复旧程序；用户资料保持
```

没有 Developer ID 证书，程序为本地签名、未公证。安装脚本只处理 `/Applications/搞截图.app`，保留旧程序直到实机验收成功，不卸载竞品，不重置 TCC 或全局系统登记。

## GaoAction V1

资源 `GaoCapabilities.json` 声明七项提供方能力：`capture.region/window/display`、`ocr.files`、`images.annotate`、`images.pin`、`text.translate`，参数严格按任务契约。外部包验证版本、目标、TTL、大小、FD路径与摘要，复制至私有 staging，用户确认后启动。结果在实际动作后生成，用户点“发送结果”才显式交给来源 App；仅打开标注/翻译页面返回 pending。重复请求与重启不重放业务。

`relativePath` 相对于包内 `payload/` 目录，不带该目录前缀。结果 `parameters={}`；成功 `errorCode` 可省略。OCR逐输入/输出关联 `sourceItemID/sourceSHA256/resultItemID`；翻译使用 `networkUsed`。本地 fixture 与双方真实编解码通过不等于已安装双方端到端验收。

## 验证状态与边界

| 状态 | 范围 |
|---|---|
| 隔离样本与针对性测试 | 坐标/scale/旋转算法、重叠拼接像素、标注撤销/裁剪/旋转/栅格回读、备份恢复演练与异常保护、路径/链接/幂等/未来schema；真实 Vision 自建中英/双栏/旋转PDF识别、PDFKit查找与选取位置；自建媒体真实H.264/AAC双轨、暂停修正、音频-only、GIF、恢复读取 |
| 部分实现 | 长截图限同屏向下有界拼接；复杂布局/数学/手写 OCR 不保证正确；录制失败只能恢复实际可解码中间媒体 |
| 未实现 | 默认云服务；第二个全局划词监听；无限长磁盘tile拼接；HDR输出目标 |
| 未验收 | Finder/Safari/TextEdit/Terminal真实截图与窗口、真实系统音/麦克风/暂停播放、当前签名TCC、真实跨App完整端到端；外屏/外置鼠标/耳机切换因当前缺设备或未连接未验收 |
| 系统条件 | 翻译只使用系统实际支持且经用户授权安装的语言包；各版本的专项翻译结果见 Release 说明。部分15+能力有availability守卫，低版本明确提示 |

V1.00 的历史完整隔离回归与 V1.01 的改动相关测试分别保留，本轮未自动运行完整旧套件或冒烟测试。真实证据在本机 `TestResults`，不进入 Git、源码包或 Release。样本条件和单次耗时只说明该次运行：首个OCR冷启动曾14.344秒，后续页面约0.1秒；实际捕获延迟与实录CPU/掉帧仍待验收。不宣传倍数或所有硬件支持。

## 原创资源与依赖

图标是原生 CoreText 字形轮廓与几何绘制，纯灰#777777、860色块、透明外边、白色竖排“截图”。真实笔画框约295×601，笔画等效面积为搞文件参考图标的99.89%。可用 `Scripts/GenerateIcon.swift` 和 `MakeIcon.swift` 再生。

Apple 系统框架之外，只使用固定版本 Ma Shan Zheng 字体作为源码再生工具，许可和摘要见 `Scripts/Fonts` 与 `THIRD_PARTY_NOTICES.md`。字体不需要随程序安装到系统；没有 ffmpeg 或竞品资源/代码。
